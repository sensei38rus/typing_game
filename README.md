Клавиатурный тренажер (Typing Game) — v2

Прогрессивный игровой тренажер скоропечатания, разработанный на языке Python с использованием библиотеки Pygame. Проект спроектирован по модульному принципу (Low Coupling) с четким разделением бизнес-логики, графического интерфейса и слоев сохранения данных, а также полностью интегрирован с Docker для изолированного тестирования.

---

## ✨ Основные возможности

* Конечный автомат (State Machine): Игровой процесс жестко контролируется состояниями (STARTING, PLAYING, RESTARTING, LEVEL_COMPLETE, GAME_OVER), обеспечивая предсказуемое поведение приложения.
* Динамическая система уровней: Слова вынесены в конфигурационные JSON-файлы. Новые уровни подгружаются автоматически без изменения кода.
* Система комбо и очков: Множитель (Combo) растет при последовательном безошибочном вводе слов и сбрасывается при таймауте, мотивируя к чистой печати.
* Асинхронный потоковый таймер: Отсчет времени вынесен в отдельный поток (threading.Thread), что полностью исключает микрофризы интерфейса при рендеринге полосы времени.
* Полноценная статистика и персистентность: Игра сохраняет лог успешных и провальных попыток с таймстампами в user_data/progress.json и рассчитывает кумулятивную точность (Accuracy) игрока.
* Полная Docker-интеграция: Наличие Dockerfile и docker-compose.yml позволяет разворачивать проект и запускать автотесты в гарантированно чистом окружении независимо от хост-системы.
* Автоматизация через `Makefile`: Все рутинные действия (установка, запуск, тесты, очистка, Docker) сведены к лаконичным командам.


🚀 Быстрый старт
Проект поддерживает два режима работы: локальный и изолированный (через Docker).
Вариант А: Запуск в Docker (Рекомендуется для тестирования)
Для сборки образов настроены зеркала, что гарантирует скачивание базовых пакетов в любых сетевых условиях.
Сборка Docker-образа:
Bash
make docker-build
Запуск модульных тестов в контейнере:
Bash
make docker-test
Тесты выполняются в изолированной Linux-среде, монтируя локальную папку для обмена результатами.
Вариант Б: Локальный запуск (Для игры и разработки)
Убедитесь, что на вашем компьютере установлен Python 3.12+ и утилита make.
Автоматическая установка зависимостей:
Bash
make install
Запуск игры:
Bash
make run
Локальный запуск тестов:
Bash
make test
Очистка временных файлов (__pycache__, кэш pytest):
Bash
make clean
⚙️ Управление и правила игры
Подготовка (STARTING): Перед стартом уровня запускается 3-секундный обратный отсчет. Набор текста заблокирован.
Набор текста (PLAYING): Вводите слово, отображаемое по центру. Клавиша Backspace стирает последний символ.
Подтверждение: Для проверки слова необходимо нажать Enter.
Если слово совпало — начисляются очки, комбо увеличивается, выдается следующее слово.
Если слово не совпало — буфер очищается, вы можете попробовать набрать его заново, пока идет время.
Таймаут (RESTARTING): Если индикатор времени иссяк — фиксируется провал, комбо сбрасывается до 1, а текущий уровень откатывается к первому слову.
Выход: Нажатие клавиши ESC или закрытие окна мышью прерывает игру с автоматическим сохранением накопленного прогресса.
🛠 Кастомизация
Вы можете расширять списки слов, создавая новые файлы в директории data/levels/ по следующему шаблону (level4.json):
JSON
{
  "name": "Продвинутый уровень — Термины",
  "words": [
    "контейнеризация",
    "асинхронность",
    "инкапсуляция",
    "полиморфизм"
  ]
}
