# 1. Терминология и глоссарий

- **Целевое слово (Target Word)** — текстовая строка, которую игрок должен безошибочно набрать на клавиатуре за ограниченный промежуток времени.

- **Пользовательский ввод (User Input)** — текущая последовательность символов, набранная игроком в процессе попытки воспроизведения целевого слова.

- **Игровое комбо (Combo)** — множитель очков, поощряющий игрока за непрерывную серию безошибочно введенных слов.

- **Таймаут (Timeout)** — событие, происходящее при полном истечении времени, отведенного на ввод текущего слова.

- **Игровой счет (Score)** — числовой эквивалент успешности игрока, увеличивающийся при каждом правильном вводе.

# 2. Сущности предметной области (Entities & Value Objects)

## 2.1. Слово (Word)

Центральный объект манипуляции.

- **Состояние:** Строковое значение, длина слова (количество символов).
- **Поведение:** Предоставляет себя для посимвольного сравнения с пользовательским вводом.

## 2.2. Уровень (Level)

Контейнер, формирующий законченный этап игры.

- **Состояние:** Уникальное имя уровня, упорядоченный массив слов, порядковый индекс.
- **Поведение:** Контролирует выдачу слов. Уровень считается успешно пройденным, когда все слова из его массива были введены игроком.

## 2.3. Игровой сеанс (Game Session / State Machine)

Агрегатор, управляющий текущим ходом игры и координирующий все сущности.

- **Состояние:** Текущий уровень, текущее слово, буфер ввода, комбо, набранные очки, а также статус игры (конечный автомат).

### Конечный автомат состояний (Finite State Machine):

- **`STARTING`** — состояние подготовки перед стартом уровня. Ввод заблокирован, на экране идет обратный отсчет для концентрации внимания.
- **`PLAYING`** — состояние активного набора. Таймер уменьшается, система ожидает от игрока либо подтверждения строки, либо наступления таймаута.
- **`RESTARTING`** — штрафное состояние, активирующееся при таймауте. Игровой процесс замораживается на короткую паузу, информируя об ошибке, после чего уровень сбрасывается к началу.
- **`LEVEL_COMPLETE`** — промежуточное состояние триумфа при успешном завершении текущего набора слов. Осуществляет переход к следующему этапу.
- **`GAME_OVER`** — терминальное состояние. Наступает, когда все доступные уровни успешно завершены. Выводит финальный результат.

## 2.4. Метрики игрока (Player Metrics / Stats)

Сущность, отвечающая за долгосрочный учет эффективности пользователя.

- **Состояние:** Исторический лог успешных вводов (слово + точное время) и лог провалов по таймауту (слово + точное время).
- **Поведение:** Позволяет на лету вычислять общую продуктивность набора.

# 3. Бизнес-правила (Business Rules)

## 3.1. Валидация ввода и управление комбо

Сравнение пользовательского ввода с целевым словом происходит строго по нажатию клавиши подтверждения (**Enter**).

- **Если ввод совпадает с целевым словом:**
    - Слово считается пройденным.
    - Счетчик комбо увеличивается на $1$.
    - Игроку начисляются очки.

- **Если ввод не совпадает со словом** на момент нажатия Enter — строка сбрасывается, давая игроку возможность продолжить набор, пока не истекло время.

- **Если время истекает (Таймаут):**
    - Попытка признается неудачной.
    - Множитель комбо немедленно сбрасывается к базовому значению ($1$).
    - Текущий уровень откатывается к самому первому слову (штраф за невнимательность).

## 3.2. Математика начисления очков

Количество очков, начисляемых за успешный ввод, прямо пропорционально длине набранного слова L и текущему множителю комбо C:

ΔScore = L × C × BasePoints

Это правило стимулирует игрока не только печатать быстро, но и сохранять непрерывную серию побед, так как длинные слова на высоком комбо приносят экспоненциально больше очков.

## 3.3. Расчет точности (Accuracy)

Точность является кумулятивным показателем за весь период работы приложения (или за текущую сессию) и вычисляется как отношение успешных попыток к общему числу исходов:


`Accuracy = N_success / (N_success + N_fail) × 100%`

Где `N_success` — количество слов, подтвержденных игроком вовремя, а `N_fail` — количество слов, по которым был зафиксирован таймаут. В случае полного отсутствия активности `N_success + N_fail = 0` точность по умолчанию составляет `100%`.
